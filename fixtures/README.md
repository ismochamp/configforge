# Verification fixtures

These small inputs are intentionally constructed test fixtures. They are not historical customer files or evidence of a customer engagement. They exercise the real migration engine and make the project reproducible. Replace them with your own authorized UTF-8 source files to perform a migration.

`mapping.tsv` contains four tab-separated columns per line: source name, output JSON key, type, and required (`true` or `false`). There is no header row in the mapping file.
